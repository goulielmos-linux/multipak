# Brand assets

The installer and manager icons are maintained in `src/multipak/kirigami/assets`.
Edit the SVG files and update the corresponding PNGs when changing an icon.
The PNGs support desktop launchers and icon caches.

The desktop IDs are:

- `io.github.multipak.installer`
- `io.github.multipak.manager`

The desktop launchers in `data` reference these icons.
